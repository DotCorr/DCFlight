# Changelog

## 0.1.0

Initial isolated development-time compiler: canonical typed IR, equivalent JSON/restricted Dart frontends, strict validation, SwiftUI and Android Views generators, hash-based conflict-safe synchronization, reviewed capability registry, schema and bulk SDK ingestion harnesses, read-only MCP tooling, and native independence verification.

DC Dart was not changed. This is a local compiler implementation, not a published DC Dart release.
