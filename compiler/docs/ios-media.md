# Generated iOS media adapters

The routed compiler emits `NativeMedia.swift` as ordinary SwiftUI, PhotosUI, UIKit and ImageIO source. It supplies no screen layout, app messages, service endpoints, sharing rules, or runtime registry. Both loading and failure content are authored child nodes. Camera capture and MapKit surfaces are not part of this implementation yet.

Implemented canonical inputs are transient MediaState/MediaRef, authored PhotoOptions, library PickPhotoEffect with success/cancel/failure flow targets, ClearMediaEffect, MediaBody on ordinary RequestEffect, mediaBytes/mediaWidth/mediaHeight/hasMedia projections, localImage and origin-scoped authenticated remoteImage. Native photo data remains in memory and never enters state restoration, defaults, logs, arbitrary file paths, or JSON. Picker-owned temporary files are read with the authored input bound before image processing. Cancelling selection preserves the previous media value; clearing a target invalidates only that target's pending acquisition. CancelEffect also invalidates acquisition alongside the HTTP request channel.

PHPicker provides the OS image selection surface. Presentation waits for the host controller to attach, follows an existing presented sheet, and never supplies app-specific controls. Selected-file decoding runs off the main actor. ImageIO reads source dimensions before thumbnail decode, rejects multiple frames and over-limit sources, applies orientation, downsamples to the authored edge, composites transparency onto white, re-encodes JPEG without source metadata, and enforces the output byte bound. Limits and JPEG quality come from canonical PhotoOptions. Shared DC Dart owns subsequent upload/send acceptance decisions.

Raw upload snapshots the prepared bytes and uses the existing typed request path, bearer, status and atomic JSON outputs. A remote image gets its own bounded URLSession task so it cannot supersede a chat request. The transport refuses redirects and disk/cookie caches. The source origin comes only from the declared transport. Identity includes address, bearer and decoding limits; a prior account's loaded image is excluded immediately when identity changes. Disappearance releases pixels and cancels the view task. The authored visibleWhen state can remove expired story images; no native24-hour rule exists.

Flow navigation callbacks hold the originating router weakly. A permanently released local host receives no later navigation, while global reset actions retain a separate weak reference to the outer host. No asynchronous completion searches for the current tab. Model-owned timers emit direct checked clock reads and shared flow calls, cancel at model disposal, and cannot initiate network/UI effects under canonical validation. ClockEffect rejects dates outside the currently declared nonnegative Int32 epoch range rather than truncating them. ReadCollectionEffect copies fully typed fields only after a matching row is found.

## Verification

`python3 -m unittest discover -s tests -p 'test_ios_*.py'` includes native SDK typechecks of generated media, collection, timer and routed sources. `python3 tools/verify_ios_media.py --simulator <booted-UDID> --work-dir <scratch-directory>` compiles the exact current helpers and executes a simulator command-line fixture without changing the visible application. It checks orientation, JPEG output, white alpha matte, GPS/private EXIF removal, malformed input, source bytes, source pixels, output bytes, multiple frames and bounded provider reads. Reports contain source, fixture and binary hashes.

The actual shared127-node app has passed a signed iOS simulator build with these adapters. Native helper execution does not establish interactive system-picker correctness, end-to-end photo delivery, camera hardware operation or production readiness. Those require separate execution evidence.
